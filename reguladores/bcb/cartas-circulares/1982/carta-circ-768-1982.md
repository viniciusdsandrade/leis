# Carta Circular nº 768, de 17 de junho de 1982

CARTA-CIRCULAR Nº 768. Aos Bancos de Investimento e Sociedades de Arrendamento Mercantil Comunicamos que o crescimento das operações sob controle, de que trata a Resolução nº 717, de 22.12.81, obedecerá a programação a seguir, mantendo-se, entretanto, para cada.um dos meses do período, razão de proporcionalidade com a sazonalidade da de manda de crédito:

Período Percentual de crescimento Base de crescimento

3º trim./82 13,00 Valores máximos permitidos Para o 2º trimestre/82 valores 4º trim/82 15,00 Máximos permitidos para o 3º Trimestre/82

2. Em conseqüência, o crescimento de tais operações, no ano de 1982, não poderá exceder a 60% dos valores máximos permitidos para o mês de dezembro de 1981. 3. Fica revogada, a partir 1º .07.82, a Carta-Circular nº 732, de 18.03.82. Brasília (DF), 17 de junho de 1982. DEPARTAMENTO DE FISCALIZAÇÃO DO MERCADO DE CAPITAIS Deli Borges CHEFE Este texto não substitui o publicado no DOU e no Sisbacen.
