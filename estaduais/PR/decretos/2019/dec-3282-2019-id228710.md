# Decreto 3282 - 08 de Novembro de 2019

Decreto 3282 - 08 de Novembro de 2019

Publicado no Diário Oficial nº. 10561 de 8 de Novembro de 2019

**Súmula:** Nomeia servidores para para exercerem, em comissão, os cargos do Departamento de Trânsito do Paraná.
